## Featured Projects

### Smart Sign Language Translator Glove

A wearable glove that reads hand gestures and converts them into readable text. Flex sensors track finger bending and an MPU6050 handles hand orientation, and the ESP32 processes that data to identify the gesture. Output is shown on an OLED display and can also be sent over Bluetooth.

**Tech:** ESP32, Flex Sensors, MPU6050, OLED Display, Bluetooth, C++

### Smart Farming Assistant

An AI and IoT based project aimed at helping with common farming problems. The idea is to detect crop diseases from images, monitor soil conditions, check when irrigation is needed, and flag agricultural risks early. It uses an ESP32-CAM and sensors for data collection, with a Raspberry Pi handling the heavier computer vision and machine learning work.

**Tech:** ESP32-CAM, Raspberry Pi, Sensors, Computer Vision, Machine Learning, Python
