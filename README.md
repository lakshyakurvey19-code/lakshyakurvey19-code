### 🚀 Featured Projects

#### 🧤 Smart Sign Language Translator Glove
An assistive wearable device built to translate sign language gestures into readable text in real time.
- **How it works:** Flex sensors detect finger movements while an MPU6050 accelerometer/gyroscope tracks hand orientation. An ESP32 microcontroller processes the sensor inputs, shows the detected message on an integrated OLED display, and transmits the text wirelessly over Bluetooth to a connected mobile device or computer.
- **Technologies Used:** ESP32, C++, Flex Sensors, MPU6050, 0.96" OLED Display, Bluetooth Serial, Arduino IDE.

#### 🌱 Smart Farming Assistant
An AI and IoT-based agricultural monitoring project designed to assist in monitoring field health and crop conditions.
- **How it works:** Combines ground sensors with an ESP32-CAM and a Raspberry Pi. The system monitors soil moisture, climate conditions, and irrigation needs while using computer vision and machine learning models to detect crop leaf diseases and evaluate agricultural risks.
- **Technologies Used:** Python, ESP32-CAM, Raspberry Pi, Computer Vision, Machine Learning, Soil & Climate Sensors.
